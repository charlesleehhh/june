## june 项目改造：静态海报 → 「果价雷达」iPhone 18 Pro 全网比价站

**背景**：原 `index.html` 只有 38 行，是一张硬编码的「向上研究所 · A股 AI 科技趋势雷达」静态海报，
所有数字（68/100 温度、OBSERVE 状态、产业链板块）都是写死的文案，没有数据、没有交互。

**方向确认（用户四次选择）**：实用小工具站 → 主题改为多平台 iPhone 18 Pro 价格跟踪 →
需要后台录入 → 需要用户注册 → 想加后端和数据库。

**后端决策**：调用 `workbuddy_cloud_service` activate 时**用户在确认框中点了拒绝**
（`declinedByUser: true` + `useLocalImplementation: true`），按 skill 规则改为本地实现：
数据用静态 `data/prices.json` 承载，改文件 → git 提交 → 现有自动部署上线。
因此**注册登录没做**，「我的关注」退化为 localStorage 本机保存（页面已明确标注）。

**产出结构（仓库根目录）**：
- `index.html` / `styles.css` / `app.js` —— 单页应用，hash 路由 5 个视图：
  比价总览 / 价格走势 / 行情大事记 / 我的关注 / 数据维护
- `data/prices.json` —— 8 个机型配置 × 6 个渠道，72 条价格记录 + 5 条行情事件
- 渠道：Apple 官网、Apple 天猫官旗、京东自营、中国联通天猫旗旗店、拼多多百亿补贴、得物
- 走势图是手写 SVG（无外部依赖）；「数据维护」页可视化录入 → 导出 prices.json 覆盖仓库
- 旧的静态海报已备份到 /tmp/june-index-legacy.html，git 历史里也能找回

**验证**：用 jsdom 写了 24 项 DOM 冒烟测试，全部通过（含切换机型、图例交互、关注增删、
录入表预填与变动提示）。测试脚本在 /tmp/smoke.js（不入库，公开目录不放测试文件）。
